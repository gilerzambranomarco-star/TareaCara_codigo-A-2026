Acerca de TareaClara

¿Para quién es?

Para estudiantes que necesitan un lugar simple donde anotar sus entregas y no olvidar fechas límite.

Cómo funciona

Tus tareas se guardan en este navegador (localStorage). No se envía ningún dato a servidores externos.

Accesibilidad

Todo el sitio se puede usar solo con el teclado. Use Tab para avanzar, Enter para activar y Espacio para marcar casillas.
