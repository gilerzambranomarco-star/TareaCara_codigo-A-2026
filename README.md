# TareaClara
Agenda de tareas académicas. Proyecto de medio ciclo – Desarrollo basado en plataformas (UTM).
HTML, CSS y JavaScript nativos (sin frameworks ni librerías). Los datos se guardan en localStorage.

## Publicar en GitHub Pages
1. Crear un repositorio público (por ejemplo `tareaclara`) y subir estos archivos en la raíz.
2. Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)`.
3. La app queda en `https://USUARIO.github.io/tareaclara/`.
Cada integrante debe hacer sus propios commits (`git config user.name` / `user.email`).
